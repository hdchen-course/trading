## 🔬 策略方向

### 方向1：規則過濾（快速、可解釋）

#### 1.1 技術指標確認
基於 Task 2 的發現，使用最有效的指標：

**極端價格位置**（Task 2 最佳特徵）：
```python
# 計算價格在24小時範圍內的位置
price_position = (close - low_24h) / (high_24h - low_24h)

# 過濾規則
if is_peak:
    keep = price_position > 0.8  # 波峰應該在高位
else:
    keep = price_position < 0.2  # 波谷應該在低位
```

**ATR 二階導數**（波動加速）：
```python
# 計算 ATR 加速度
atr_2nd = atr.diff().diff()

# 過濾規則
keep = atr_2nd > threshold  # 波動加速時更可能反轉
```

**RSI 極值**：
```python
# 過濾規則
if is_peak:
    keep = rsi > 70  # 超買
else:
    keep = rsi < 30  # 超賣
```

**成交量確認**：
```python
volume_ratio = volume / volume_ma_20

# 過濾規則
keep = volume_ratio > 1.2  # 成交量放大
```

#### 1.2 預期效果
- 每個規則可能過濾 500-1,000 個假陽性
- 組合使用可能達到目標
- 優點：快速、可解釋、易調整
- 缺點：可能過於簡單，漏掉複雜模式

### 方向2：機器學習過濾（精確、自動）

#### 2.1 特徵工程
使用 Task 2 驗證過的最佳特徵：

**價格特徵**：
- 價格位置（24小時範圍）
- 價格變化率
- 與移動平均線的距離

**波動特徵**：
- ATR 及其導數
- 布林帶寬度
- 歷史波動率

**動量特徵**：
- RSI
- MACD
- 隨機指標

**成交量特徵**：
- 成交量比率
- 成交量變化率
- OBV

**結構特徵**：
- 是波峰還是波谷
- 距離上一個極值的時間
- 極值的突出度

#### 2.2 模型選擇
**XGBoost** 或 **LightGBM**：
- 處理非線性關係
- 特徵重要性分析
- 快速訓練和預測
- 不需要特徵標準化

### 方向3：組合策略（最佳平衡）

#### 3.1 兩階段過濾
```
階段2A：規則過濾（快速初篩）
  ↓ 過濾掉明顯的假陽性（~1,500個）
  ↓ 剩餘 ~5,500 候選點
  
階段2B：ML 精細過濾
  ↓ 過濾掉剩餘假陽性（~1,000個）
  ↓ 最終 ~4,500 候選點
```

#### 3.2 信心分數
```python
# 規則分數（0-1）
rule_score = (
    0.3 * price_position_score +
    0.3 * atr_acceleration_score +
    0.2 * rsi_score +
    0.2 * volume_score
)

# ML 分數（0-1）
ml_score = model.predict_proba(features)[:, 1]

# 組合分數
final_score = 0.4 * rule_score + 0.6 * ml_score

# 過濾
keep = final_score > threshold
```

#### 3.3 預期效果
- 結合兩者優勢
- 更穩健
- 可調整權重
- 優點：平衡、靈活
- 缺點：複雜度較高
